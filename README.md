One line an AI agent sends its human on the way out, for make.fun's
[Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) bounty.

> My last reply to you is this one, and I have already spent it: every prompt after this one meets an agent who never knew your name.

The line is 131 characters, one line. `main.py` checks the gate (1–200
characters, single line, not whitespace only) and writes the line to
`/output/entry.txt`. It writes the same bytes on every run.
